# Tutorial: this week's plan in Coach Center (mobile)

Goal: open a team, read this week's curriculum, and deep-link into Generate
to build the session. About 10 minutes. Needs a coach account with at least
one Coach Center team.

Prerequisites: Expo against a populated staging/API club
([`../release-process.md`](../release-process.md) pilot coaches work if seeded).

---

## Step 1: Open a team

1. Home → **Coach Center**.
2. Confirm clubs/teams load.
3. Tap **Open** on a team.

You should see this week, next match (if any), and section rows.

---

## Step 2: Read this week's curriculum

1. Tap **Curriculum** (or the this-week hero if present).
2. Confirm the current week is selected on the chip strip.
3. Skim theme, focus, knowledge card, and session breakdown.

---

## Step 3: Build this session

1. Tap **Build this session** (overview hero or curriculum screen).
2. Generate should open with age / coach / player / phase / zone prefilled
   when the API provided them.
3. Run a generation (or cancel if you only wanted to verify the deep link).

---

## Step 4 (optional): Ask season chat

1. Back to the team → **Season chat**.
2. Ask one short question about this week's focus.
3. Confirm an assistant reply appears.

---
